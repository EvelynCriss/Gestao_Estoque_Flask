# Sistema de Gestão de Estoque (Flask + MVC)

## Descrição

Este projeto consiste no desenvolvimento de um sistema de **gestão de estoque**, criado com o objetivo de auxiliar no controle de produtos, fornecedores e pedidos.

A aplicação foi desenvolvida utilizando o framework Flask, seguindo o padrão de arquitetura **MVC (Model-View-Controller)**, garantindo melhor organização, manutenção e escalabilidade do sistema.

---

## Arquitetura do Projeto

O sistema foi estruturado com base no padrão MVC, separando responsabilidades em três camadas principais:

* **Models:** responsáveis pela representação das entidades do sistema e interação com o banco de dados.
* **Controllers:** responsáveis pela lógica de negócio e controle das rotas da aplicação.
* **Views:** responsáveis pela interface do usuário, utilizando templates HTML com Jinja2.

---

## Tecnologias Utilizadas

* **Python**
* **Flask**
* **MySQL**
* **HTML5**
* **CSS3**
* **Jinja2**
* **Java Script**

---

## Banco de Dados

O sistema utiliza um banco de dados relacional (**MySQL**), com tabelas interligadas por meio de **chaves estrangeiras**, garantindo integridade e consistência dos dados.

---

## Objetivo do Projeto

O sistema foi desenvolvido com foco em:

* Organização de dados de estoque
* Controle de entradas e saídas
* Aplicação prática da arquitetura MVC
* Integração entre backend, frontend e banco de dados
